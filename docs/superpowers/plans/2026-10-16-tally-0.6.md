# Tally 0.6 Beta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add supersets, three new exercise types, Apple Watch (Apple Health) workout import and merging, a weekly recap and an add-reps shortcut to Tally.

**Architecture:** Plain logic (superset links, timer-style time entry, pace, overlap matching, recap numbers) goes into a new local Swift package `Packages/TallyCore` that only imports Foundation, so it is unit-tested on Linux in WSL with Swift Testing. The app target (`Sources/Tally`) depends on it and wires it into the existing SwiftUI views, `GymStore` and `HealthManager`. A small `HealthSync` coordinator connects HealthKit reads/writes to `GymStore`.

**Tech Stack:** Swift 6.4, SwiftUI (iOS 26.1), HealthKit, WidgetKit, App Intents, Swift Testing, xtool 1.22.2 in WSL Ubuntu-24.04.

**Spec:** `docs/superpowers/specs/2026-10-15-tally-0.6-design.md`

## Global Constraints

- Deployment target stays `.iOS("26.1")`; Swift 6 language mode with strict concurrency.
- `Packages/TallyCore` imports only Foundation (no SwiftUI, HealthKit, UIKit) so `swift test` runs on Linux.
- Workouts, plans and exercises saved by 0.5 must decode and display unchanged: every new stored property is optional or has a default (Swift's synthesized `Codable` decodes missing optionals as nil).
- JSON key for plans stays `"routines"`; bundle ID, App Group and widget kinds are unchanged.
- UI copy: plain and factual, no slogans or emoji.
- Commits: Conventional Commits, one per task, **no** `Co-Authored-By` trailer.
- Version 0.6, build 6 in both `Support/Tally-Info.plist` and `Support/TallyWidget-Info.plist`.

## Review Focus

1. **0.5 data with an assisted machine.** A 0.5 workout logged "Assisted Pull-up (Machine)" with weight 30 × 8. After 0.6 loads, the set shows "−30 kg × 8", adds 0 kg to volume and is not a "heaviest weight" record. Pinned by the migration step and phone check in Task 5.
2. **A Watch workout still running or with zero length.** Overlap matching must not divide by zero or match an empty interval. Pinned by `overlapIgnoresEmptyIntervals` in Task 6.
3. **A workout that starts late Sunday.** The recap counts it in the week it started, and a session at exactly Monday 00:00 belongs to the new week. Pinned by `totalsUseStartDateAndExcludeNextMonday` in Task 9.
4. **Typing 90 into a time field.** It means 90 seconds and shows as 1:30 once the field loses focus, not 0:90. Pinned by `ninetySecondsRedisplaysAsOneThirty` in Task 4 and the `TimeField` focus handling in Task 5.
5. **Removing or moving an exercise out of a superset of two.** The remaining exercise is no longer marked as a superset, and the rest timer starts after it again. Pinned by `normalizedKeepsNeighboursAndClearsLoners` and `restOnlyAfterLastExerciseOfGroup` in Task 2, plus the phone check in Task 3.

```swift
// Packages/TallyCore/Sources/TallyCore/Supersets.swift
import Foundation

/// Superset links for an ordered list of exercises. Each exercise has an optional group ID;
/// neighbours with the same ID form one superset.
public enum Supersets {
    /// Where an exercise sits in its superset, for drawing the group bar.
    public enum Position: Equatable, Sendable {
        case none, first, middle, last
    }

    /// Clears IDs that no longer link at least two neighbouring exercises.
    public static func normalized(_ ids: [UUID?]) -> [UUID?] {
        ids.indices.map { position(at: $0, in: ids) == .none ? nil : ids[$0] }
    }

    public static func position(at index: Int, in ids: [UUID?]) -> Position {
        guard ids.indices.contains(index), let id = ids[index] else { return .none }
        let before = index > 0 && ids[index - 1] == id
        let after = index + 1 < ids.count && ids[index + 1] == id
        switch (before, after) {
        case (false, false): return .none
        case (false, true): return .first
        case (true, true): return .middle
        case (true, false): return .last
        }
    }

    /// Whether finishing a set of the exercise at `index` should start the rest timer: only when
    /// the next exercise isn't in the same superset.
    public static func restsAfter(index: Int, in ids: [UUID?]) -> Bool {
        let position = position(at: index, in: ids)
        return position == .none || position == .last
    }

    /// Links the exercise at `other` into the superset of the exercise at `anchor`; `other` moves to
    /// just after the anchor's group. Returns the new order (indices into the original list) and
    /// the IDs in that order.
    public static func link(_ anchor: Int, with other: Int, in ids: [UUID?], newID: UUID = UUID()) -> (order: [Int], ids: [UUID?]) {
        guard anchor != other, ids.indices.contains(anchor), ids.indices.contains(other) else {
            return (Array(ids.indices), ids)
        }
        let groupID = ids[anchor] ?? newID
        var updated = ids
        updated[anchor] = groupID
        updated[other] = groupID

        var order = Array(ids.indices).filter { $0 != other }
        guard var end = order.firstIndex(of: anchor) else { return (Array(ids.indices), ids) }
        // Walk to the end of the anchor's original group (the moved exercise is already out).
        while end + 1 < order.count, let anchorID = ids[anchor], ids[order[end + 1]] == anchorID {
            end += 1
        }
        order.insert(other, at: end + 1)
        return (order, normalized(order.map { updated[$0] }))
    }

    /// The same groups with new IDs, for copying exercises into another workout or plan.
    public static func renewed(_ ids: [UUID?], makeID: () -> UUID = { UUID() }) -> [UUID?] {
        var mapping: [UUID: UUID] = [:]
        return ids.map { id in
            guard let id else { return nil }
            if let new = mapping[id] { return new }
            let new = makeID()
            mapping[id] = new
            return new
        }
    }
}
```

```swift
// Sources/Tally/Gym/WorkoutExercise+Supersets.swift
import Foundation
import TallyCore

extension Array where Element == WorkoutExercise {
    var supersetIDs: [UUID?] { map(\.supersetID) }

    func supersetPosition(of id: WorkoutExercise.ID) -> Supersets.Position {
        guard let index = firstIndex(where: { $0.id == id }) else { return .none }
        return Supersets.position(at: index, in: supersetIDs)
    }

    /// Clears superset links that no longer join two neighbouring exercises.
    mutating func normalizeSupersets() {
        let ids = Supersets.normalized(supersetIDs)
        for index in indices { self[index].supersetID = ids[index] }
    }

    /// Puts `other` in a superset with `anchor`, moving it next to the anchor's group.
    mutating func linkSuperset(_ anchor: WorkoutExercise.ID, with other: WorkoutExercise.ID) {
        guard let anchorIndex = firstIndex(where: { $0.id == anchor }),
              let otherIndex = firstIndex(where: { $0.id == other }) else { return }
        let result = Supersets.link(anchorIndex, with: otherIndex, in: supersetIDs)
        var reordered = result.order.map { self[$0] }
        for index in reordered.indices { reordered[index].supersetID = result.ids[index] }
        self = reordered
    }

    /// Takes an exercise out of its superset and places it just after the group.
    mutating func unlinkSuperset(_ id: WorkoutExercise.ID) {
        guard let index = firstIndex(where: { $0.id == id }), let group = self[index].supersetID else { return }
        var end = index
        while end + 1 < count, self[end + 1].supersetID == group { end += 1 }
        var exercise = remove(at: index)
        exercise.supersetID = nil
        insert(exercise, at: end)
        normalizeSupersets()
    }

    /// Exercises that `id` can join in a superset: every other exercise not already in its group.
    func supersetCandidates(for id: WorkoutExercise.ID) -> [WorkoutExercise] {
        let group = first { $0.id == id }?.supersetID
        return filter { $0.id != id && (group == nil || $0.supersetID != group) }
    }

    /// The same exercises with new superset IDs, so a copy doesn't share groups with the original.
    func withRenewedSupersets() -> [WorkoutExercise] {
        let ids = Supersets.renewed(supersetIDs)
        var copy = self
        for index in copy.indices { copy[index].supersetID = ids[index] }
        return copy
    }
}
```

```swift
// Packages/TallyCore/Sources/TallyCore/TimeEntry.swift
import Foundation

/// Timer-style time entry: digits fill from the right, so typing 2, 5, 0, 0 gives 25:00.
public enum TimeEntry {
    public static let maxDigits = 6

    /// Only the digits of `text`, without leading zeros, at most `maxDigits`.
    public static func cleaned(_ text: String) -> String {
        let digits = text.filter { $0.isASCII && $0.isNumber }.drop { $0 == "0" }
        return String(digits.prefix(maxDigits))
    }

    /// Seconds for typed digits: the last two are seconds, the two before minutes, the rest hours.
    /// Values over 59 are allowed while typing ("90" is 90 seconds).
    public static func seconds(fromDigits digits: String) -> Int? {
        guard let value = Int(digits), value > 0 else { return nil }
        return (value / 10_000) * 3600 + (value / 100 % 100) * 60 + value % 100
    }

    /// The digits that show `seconds` as h:mm:ss or m:ss.
    public static func digits(fromSeconds seconds: Int) -> String {
        guard seconds > 0 else { return "" }
        return String(seconds / 3600 * 10_000 + seconds % 3600 / 60 * 100 + seconds % 60)
    }

    /// Digits with colons, as shown while typing: "5" → "0:05", "2500" → "25:00", "12500" → "1:25:00".
    public static func display(_ digits: String) -> String {
        guard !digits.isEmpty else { return "" }
        var rest = Substring(String(repeating: "0", count: max(0, 3 - digits.count)) + digits)
        var groups: [Substring] = []
        while rest.count > 2 {
            groups.insert(rest.suffix(2), at: 0)
            rest = rest.dropLast(2)
        }
        groups.insert(rest, at: 0)
        return groups.joined(separator: ":")
    }

    /// "0:00", "1:05", "1:02:03".
    public static func format(_ seconds: Int) -> String {
        seconds > 0 ? display(digits(fromSeconds: seconds)) : "0:00"
    }
}
```

```swift
import Foundation

public enum Pace {
    /// Seconds per kilometre, or nil without both a distance and a time.
    public static func secondsPerKm(meters: Double?, seconds: Int?) -> Double? {
        guard let meters, let seconds, meters > 0, seconds > 0 else { return nil }
        return Double(seconds) / (meters / 1000)
    }

    /// "5:00 /km"
    public static func format(secondsPerKm: Double) -> String {
        "\(TimeEntry.format(Int(secondsPerKm.rounded()))) /km"
    }

    /// "800 m" under a kilometre, otherwise "5 km" or "5.25 km" with the locale's decimal separator.
    public static func distance(_ meters: Double, locale: Locale = .current) -> String {
        if meters < 1000 { return "\(Int(meters.rounded())) m" }
        let km = (meters / 1000).formatted(.number.precision(.fractionLength(0...2)).locale(locale))
        return "\(km) km"
    }
```

```swift
            case .time: return Double(sets.reduce(0) { $0 + ($1.seconds ?? 0) })
            case .assistance: return sets.filter { ($0.reps ?? 0) > 0 }.compactMap(\.assistance).min() ?? 0
            case .distance: return sets.reduce(0) { $0 + ($1.meters ?? 0) } / 1000
            case .pace:
                let timed = sets.filter { ($0.meters ?? 0) > 0 && ($0.seconds ?? 0) > 0 }
                let km = timed.reduce(0) { $0 + ($1.meters ?? 0) } / 1000
                let seconds = Double(timed.reduce(0) { $0 + ($1.seconds ?? 0) })
                return km > 0 ? seconds / km : 0
            }
        }

        var unit: String {
            switch self {
            case .heaviest, .oneRepMax, .volume, .assistance: "kg"
            case .reps: "reps"
            case .time: ""
            case .distance: "km"
            case .pace: "/km"
            }
        }

        func format(_ value: Double) -> String {
            switch self {
            case .time, .pace: Fmt.seconds(Int(value.rounded()))
            default: Fmt.weight(value)
            }
        }
    }
```

```swift
// Packages/TallyCore/Sources/TallyCore/Overlap.swift
import Foundation

/// Decides whether two recorded workouts are the same session, e.g. a Tally workout and an Apple
/// Watch workout started a few minutes apart.
public enum Overlap {
    /// Seconds the two intervals have in common.
    public static func seconds(_ a: DateInterval, _ b: DateInterval) -> TimeInterval {
        max(0, min(a.end, b.end).timeIntervalSince(max(a.start, b.start)))
    }

    /// True when they share more than half of the shorter one. Empty intervals never match.
    public static func isSameSession(_ a: DateInterval, _ b: DateInterval) -> Bool {
        let shorter = min(a.duration, b.duration)
        guard shorter > 0 else { return false }
        return seconds(a, b) > shorter / 2
    }

    /// The candidate that is the same session as `interval`, preferring the largest overlap.
    public static func bestMatch(for interval: DateInterval, in candidates: [(id: UUID, interval: DateInterval)]) -> UUID? {
        candidates
            .filter { isSameSession(interval, $0.interval) }
            .max { seconds(interval, $0.interval) < seconds(interval, $1.interval) }?
            .id
    }
}
```

```swift
// Packages/TallyCore/Sources/TallyCore/Recap.swift
import Foundation

/// A finished workout, reduced to what the weekly recap needs.
public struct SessionSummary: Sendable, Equatable {
    public var start: Date
    public var duration: TimeInterval
    public var volume: Double
    public var sets: Int
    public var records: Int
    /// Best estimated one-rep max per exercise in this session (weight exercises only).
    public var bestOneRepMax: [UUID: Double]

    public init(start: Date, duration: TimeInterval, volume: Double, sets: Int, records: Int, bestOneRepMax: [UUID: Double]) {
        self.start = start
        self.duration = duration
        self.volume = volume
        self.sets = sets
        self.records = records
        self.bestOneRepMax = bestOneRepMax
    }
}

/// A workout recorded by another app, e.g. a run on Apple Watch.
public struct ActivitySummary: Sendable, Equatable {
    public var start: Date
    public var duration: TimeInterval
    public var energy: Double?

    public init(start: Date, duration: TimeInterval, energy: Double?) {
        self.start = start
        self.duration = duration
        self.energy = energy
    }
}

public struct WeekTotals: Sendable, Equatable {
    public var workouts = 0
    public var duration: TimeInterval = 0
    public var volume: Double = 0
    public var sets = 0
    public var records = 0
    public var activities = 0
    public var activityEnergy: Double = 0

    public init() {}
}

public struct Improvement: Sendable, Equatable {
    public var exerciseID: UUID
    public var before: Double
    public var after: Double
    public var change: Double { after - before }

    public init(exerciseID: UUID, before: Double, after: Double) {
        self.exerciseID = exerciseID
        self.before = before
        self.after = after
    }
}

public struct WeeklyRecap: Sendable, Equatable {
    public var week: DateInterval
    public var totals: WeekTotals
    public var previous: WeekTotals
    /// The exercise whose best estimated 1RM rose the most against its last session before the week.
    public var mostImproved: Improvement?
}

public enum Recaps {
    /// The recap for the week containing `date`, compared with the week before.
    public static func recap(weekOf date: Date, sessions: [SessionSummary], activities: [ActivitySummary], calendar: Calendar = .current) -> WeeklyRecap? {
        guard let week = calendar.dateInterval(of: .weekOfYear, for: date),
              let previousDay = calendar.date(byAdding: .day, value: -1, to: week.start),
              let previousWeek = calendar.dateInterval(of: .weekOfYear, for: previousDay) else { return nil }
        return WeeklyRecap(
            week: week,
            totals: totals(in: week, sessions: sessions, activities: activities),
            previous: totals(in: previousWeek, sessions: sessions, activities: activities),
            mostImproved: mostImproved(in: week, sessions: sessions)
        )
    }

    /// Starts of the weeks that have at least one session, newest first.
    public static func weeks(with sessions: [SessionSummary], calendar: Calendar = .current) -> [Date] {
        Set(sessions.compactMap { calendar.dateInterval(of: .weekOfYear, for: $0.start)?.start }).sorted(by: >)
    }

    /// `DateInterval.contains` includes the end, which is the first instant of the next week.
    static func contains(_ week: DateInterval, _ date: Date) -> Bool {
        date >= week.start && date < week.end
    }

    static func totals(in week: DateInterval, sessions: [SessionSummary], activities: [ActivitySummary]) -> WeekTotals {
        var totals = WeekTotals()
        for session in sessions where contains(week, session.start) {
            totals.workouts += 1
            totals.duration += session.duration
            totals.volume += session.volume
            totals.sets += session.sets
            totals.records += session.records
        }
        for activity in activities where contains(week, activity.start) {
            totals.activities += 1
            totals.activityEnergy += activity.energy ?? 0
        }
        return totals
    }

    static func mostImproved(in week: DateInterval, sessions: [SessionSummary]) -> Improvement? {
        let earlier = sessions.filter { $0.start < week.start }.sorted { $0.start > $1.start }
        var thisWeek: [UUID: Double] = [:]
        for session in sessions where contains(week, session.start) {
            for (id, value) in session.bestOneRepMax {
                thisWeek[id] = max(thisWeek[id] ?? 0, value)
            }
        }
        var best: Improvement?
        for (id, after) in thisWeek {
            guard let before = earlier.lazy.compactMap({ $0.bestOneRepMax[id] }).first, after > before else { continue }
            let candidate = Improvement(exerciseID: id, before: before, after: after)
            // Ties go to the lower UUID string so the result doesn't depend on dictionary order.
            if let current = best,
               candidate.change < current.change
                || (candidate.change == current.change && candidate.exerciseID.uuidString > current.exerciseID.uuidString) {
                continue
            }
            best = candidate
        }
        return best
    }
}
```

```swift
// Sources/TallyKit/AddRepsIntent.swift
import AppIntents
import WidgetKit

/// Lets the system see the intents in this module from the app and the widget extension.
public struct TallyKitIntents: AppIntentsPackage {}

public struct QuickExerciseEntity: AppEntity {
    public static let typeDisplayRepresentation: TypeDisplayRepresentation = "Exercise"
    public static let defaultQuery = QuickExerciseQuery()

    public let id: UUID
    public let name: String

    public var displayRepresentation: DisplayRepresentation { DisplayRepresentation(title: "\(name)") }

    public init(id: UUID, name: String) {
        self.id = id
        self.name = name
    }
}

public struct QuickExerciseQuery: EntityQuery {
    public init() {}

    public func entities(for identifiers: [UUID]) async throws -> [QuickExerciseEntity] {
        RepStorage.load().exercises
            .filter { identifiers.contains($0.id) }
            .map { QuickExerciseEntity(id: $0.id, name: $0.name) }
    }

    public func suggestedEntities() async throws -> [QuickExerciseEntity] {
        RepStorage.load().exercises.map { QuickExerciseEntity(id: $0.id, name: $0.name) }
    }
}

public struct AddRepsIntent: AppIntent {
    public static let title: LocalizedStringResource = "Add reps"
    public static let description = IntentDescription("Adds reps to an exercise in Tally's rep counter.")

    @Parameter(title: "Exercise")
    public var exercise: QuickExerciseEntity?

    @Parameter(title: "Reps", default: 10, inclusiveRange: (1, 1000))
    public var reps: Int

    public init() {}

    public init(exercise: QuickExerciseEntity?, reps: Int) {
        self.exercise = exercise
        self.reps = reps
    }

    public func perform() async throws -> some IntentResult & ProvidesDialog {
        var data = RepStorage.load()
        guard let target = data.exercises.first(where: { $0.id == exercise?.id }) ?? data.exercises.first else {
            return .result(dialog: "There are no exercises in the rep counter.")
        }
        data.entries.append(RepEntry(exerciseID: target.id, reps: reps))
        RepStorage.save(data)
        WidgetCenter.shared.reloadTimelines(ofKind: WidgetKind.reps)
        return .result(dialog: "Added \(reps) \(target.name). \(data.repsToday()) reps today.")
    }
}
```
